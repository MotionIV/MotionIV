# اهلا أنا MotionIV 👋

اسمي الحقيقي أحمد مصطفى زكريا — مصري، والشغل بتاعي **مطور ألعاب.**

أنا بهتم بتطوير الألعاب وإنتاج محتوى، أكتر حاجه بعمله إني بوثق الحاجات على يوتيوب وأنا بشتغل. ابتديت أجرب محركات الألعاب من سنة 2019 وموقفتش بعدها.

---

## الحاجات اللي بعملها

بهتم جداً بإحساس اللعبة — الحركة، الأنيميشن. معظم وقتي بروح على gameplay systems وعشان أخلي الميكانيكس تحس صح، مش بس تشتغل. كمان بسجل كل حاجة وبشارك الفلسفة بتاعتي في التطوير.

## الأدوات اللي أستخدمها

* **المحركات:** Roblox Studio, Godot, GDevelop (ابتديت منهم، ماتحكموش على حد 😂)
* **اللغات:** Luau, GDScript, Python
